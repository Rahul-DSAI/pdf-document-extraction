# GitHub publication checklist

- [ ] Confirm permission to publish all code and generic schema examples.
- [ ] Keep source PDFs and extracted business/customer data out of the repository.
- [ ] Set `LLAMA_CLOUD_API_KEY` through a local environment variable.
- [ ] Rotate any credential that was previously embedded in source or shared archives.
- [ ] Test the Marker pipeline in a clean environment.
- [ ] Test LlamaParse with a non-sensitive sample PDF.
- [ ] Add a license only if you have the right to license this code.
